# Exercises

One file per exercise. Each file gives you the task, never the answer.

## How these briefs are written, and why

You will use an AI assistant. That is expected and it is graded. But an exercise you can
solve by pasting the brief into ChatGPT and copying what comes back teaches you nothing,
so these briefs are written to make that impossible.

Every one of them holds something the AI cannot know:

- a choice that is yours to make, and that you must state before you code
- a file you have to open and describe first, because its real shape is not written here
- a piece of work from an earlier exercise, which only exists in your own repository

Paste one of these briefs into an assistant and it will have to ask you questions before
it can write anything useful. That is the point. Answering those questions is the skill
this course is about.

## The shape of every brief

| Block | What it asks of you |
|---|---|
| **What the program must do** | The result to reach, not the steps to get there |
| **Answer these first** | Four questions, answered in comments at the top of your file, before any code |
| **What the AI cannot know** | The things only you can supply |
| **Check it yourself** | A verification to run by hand, so a program that runs wrong gets caught |

The first block of questions is always the same three, plus one specific to the exercise:

1. What goes **in**?
2. What happens to it?
3. What comes **out**?

Those three are the whole course. Every program is that shape.

## The four steps

1. **Ask** the AI, once you can describe what you want
2. **Read** the answer and comment each block in your own words
3. **Adapt** it to your file, your choices, your data
4. **Check** one case where you already know the answer
