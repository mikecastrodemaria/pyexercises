# Examples

Runnable code shown on the slides, with comments and a few extra cases.

Open a file, read the comments, then click **Run** at the top right of your editor.
Change a value, run it again, see what moves. That is how you learn faster than by reading.

These files are examples, not exercises. Nothing here has to be handed in.

| Folder | What it covers |
|---|---|
| `strings/` | Text: quotes, multi-line text, common string methods |
| `numbers/` | Integers, floats, readable large numbers |
| `lists/` | Ordered collections: indexing, slicing, adding, removing, looping |
| `dictionaries/` | Values reached by name instead of by position |
| `conditions/` | Making the program choose |
| `loops/` | Repeating work |
| `functions/` | Naming a piece of work and reusing it |
| `operators/` | Arithmetic, assignment, comparison, logical, bitwise |
| `io/` | Talking to the user and to standard input |
| `files/` | Reading and writing files, including CSV |
