| `machine_learning/` | A first look at data distribution and histograms with NumPy and Matplotlib |

These files need two libraries that are not installed by default:

```
pip install numpy matplotlib
```

Run that once in your Codespace terminal.

If you enjoy this part, the two subjects worth looking at next are regular
expressions (`../exercises/10.0_regular_expressions.py`) and pandas, the
library every data analyst uses.
